# InnovateX Sponsor Connect

SRM InnovateX 2026 – Sponsorship Website (Frontend Only)

1. Overview

The Sponsorship Website is a premium one-page landing page designed to attract companies, startups, brands, and organizations interested in sponsoring SRM InnovateX 2026, a 24-hour National Level Hackathon.

The website should establish credibility, clearly communicate sponsorship opportunities, highlight the event's impact, and encourage sponsors to contact the organizing team.

Goal: Convert visitors into sponsor leads.
